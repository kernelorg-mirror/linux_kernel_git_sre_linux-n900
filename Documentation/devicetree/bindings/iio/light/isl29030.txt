* ISL 29030 I2C ALS, Proximity, and Infrared sensor

Required properties:

  - compatible: Should be "isil,isl29030"
  - reg: the I2C address of the device
  - interrupt-parent: should be the phandle for the interrupt controller
  - interrupts: the sole interrupt generated by the device

Optional properties:

  - vdd-supply: phandle to the regulator that provides power to the sensor.
  - isil,ir-led-microamp: may be either 110000 or 220000, defaults to 110000.

Example:

isl29018@44 {
	compatible = "isil,isl29030";
	reg = <0x44>;
	interrupt-parent = <&gpio6>;
	interrupts = <17 IRQ_TYPE_LEVEL_LOW>; /* gpio177 */
	isil,ir-led-microamp = <110000>;
};
